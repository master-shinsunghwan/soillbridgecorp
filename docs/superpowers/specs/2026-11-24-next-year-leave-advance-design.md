# 다음 연도 연차 선사용 설계

## 목적

신성환 실장이 직원별 다음 연도 연차 선사용 내역을 승인 절차 없이 확정 등록하고, 다음 연도 연차가 발생할 때 해당 사용분을 자동으로 한 번만 차감한다.

## 권한과 화면

- 입력 화면은 신성환 실장 계정과 관리자에게만 표시한다.
- 서버에서도 사용자명/표시명과 관리자 역할을 검사해 화면 우회 호출을 차단한다.
- 연차 관리 화면에 `다음 연도 선사용` 탭을 추가한다.
- 입력 항목은 대상 직원, 사용일, 단위(연차/반차), 메모다.
- 목록에는 대상 연도, 직원, 사용일, 수량, 메모, 입력자, 상태(`차감 대기`/`차감 완료`)를 표시한다.
- 차감 대기 건은 잘못 입력했을 때 삭제할 수 있고, 차감 완료 건은 감사 이력으로 유지한다.

## 데이터와 처리 규칙

- 전용 장부 테이블에 `target_year`, `user_id`, `usage_date`, `unit`, `days`, `note`, `created_by`, `applied_at`, `applied_balance_id`를 저장한다.
- 사용일은 반드시 현재 연도의 다음 연도여야 한다.
- 같은 직원·같은 날짜·같은 단위의 중복 등록은 차단한다.
- 다음 연도 연차 자동 발생 시 직원별 기본 연차를 먼저 설정하고, 해당 연도의 미적용 선사용 합계를 `used_days`에 반영한다.
- 선사용 차감 후 사용일수가 총 연차를 초과하면 연차 발생 작업 전체를 중단하고 오류를 표시한다.
- 성공 시 각 선사용 행에 적용 시각과 잔여 테이블 ID를 기록해 재실행해도 중복 차감하지 않는다.
- 차감 완료 시 기존 연차 사용 이력에도 승인 완료 건을 생성해 직원의 사용일자 화면에서 확인할 수 있게 한다.

## 자동 적용 시점

- 연차 화면과 연차 API를 열 때 현재 연도의 연차 발생 여부를 확인한다.
- 새해 첫 접근에서 미발생 직원에게 기본 연차를 발생시키고 선사용분을 자동 차감한다.
- 관리자의 기존 `올해 연차 자동 발생` 버튼을 실행해도 동일한 공통 로직을 사용한다.

## 접근 방식

- 선택: 별도 선사용 장부 방식. 적용 여부와 감사 이력이 명확하고 중복 차감을 DB 상태로 방지할 수 있다.
- 제외: 미래 날짜의 기존 연차 신청을 즉시 승인 처리하는 방식. 현재 연도 잔여 계산 및 연도 초기화와 결합되어 예외 처리가 커진다.

## 검증

- 신성환 실장과 관리자만 등록·조회·대기 건 삭제가 가능하다.
- 일반 직원은 화면과 API 모두 접근할 수 없다.
- 새해 연차 발생 시 선사용분이 정확히 한 번 차감된다.
- 자동 발생을 반복 실행해도 중복 차감되지 않는다.
- 반차는 0.5일로 반영되고 기존 직원별 사용일자 이력에 나타난다.
