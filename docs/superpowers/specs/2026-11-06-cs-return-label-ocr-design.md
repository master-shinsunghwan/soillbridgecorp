# CS Return Label OCR Design

## Intent

CS처리대장에서 회수 송장 사진 여러 장을 업로드하면 송장번호와 라벨 텍스트를 추출하고, 기존 CS건과 비교해 검토 가능한 표로 보여준다. 사용자가 확인한 항목만 기존 CS건에 반영하거나 미등록 CS건으로 신규 등록하며, 같은 결과를 카카오톡 전달용 텍스트로 수정하고 복사할 수 있게 한다.

## Goals

- JPG, JPEG, PNG 사진 여러 장을 한국어/영문 Tesseract OCR로 분석한다.
- 운송장번호와 OCR 원문을 추출하고 기존 CS건의 수령자, 상품, 연락처, 주소와 비교한다.
- `일치`, `확인 필요`, `CS장부 미등록` 상태로 나누고 사용자가 필드를 수정할 수 있게 한다.
- 선택 항목만 기존 CS건에 회수운송장번호로 반영하거나 신규 CS건으로 등록한다.
- 적용된 원본 사진을 CS건에 연결해 보관한다.
- 검토 결과를 날짜 제목, 고객명, 상품, 수량, 상태, 회수송장번호 형식의 카카오톡용 텍스트로 생성한다.

## Non-goals

- OCR 결과를 검토 없이 자동 저장하지 않는다.
- 외부 유료 OCR API를 사용하지 않는다.
- 사진에서 불량 상태를 임의로 추론하지 않는다. OCR 또는 사용자 입력값만 사용한다.

## Approach

선택한 방식은 서버 Tesseract OCR + 기존 CS 데이터 점수 매칭 + 사용자 승인 후 일괄 반영이다. 브라우저 OCR은 PC별 성능과 결과가 달라 제외하고, 외부 AI OCR은 과금과 개인정보 전송 문제 때문에 제외한다.

## Data And Safety

- OCR 분석 결과는 임시 상태이며 `적용` 전에는 DB를 변경하지 않는다.
- 매칭은 이름(마스킹 포함), 전화번호 뒷자리, 상품 토큰, 주소 토큰을 점수화한다.
- 단일 후보가 충분히 앞설 때만 `일치`로 제안하고 나머지는 확인 대상으로 남긴다.
- 원본은 `/data/uploads/cs-return-labels`에 저장하고 `cs_case_attachments`에서 CS건과 연결한다.
- 같은 송장번호가 이미 등록된 경우 중복 적용을 거부한다.

## UI

CS처리대장 도구막대에 `회수송장 사진 분석` 버튼을 추가한다. 분석 창은 드래그앤드롭 영역, 진행 상태, 수정 가능한 결과 표, 원본 미리보기, 카카오톡 텍스트 편집기, `선택 항목 적용`, `텍스트 복사` 버튼으로 구성한다. 미등록 행은 붉은 배지, 확인 필요는 주황 배지, 일치는 녹색 배지로 표시한다.
