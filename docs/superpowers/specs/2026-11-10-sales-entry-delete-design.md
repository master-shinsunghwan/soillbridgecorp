# Sales Entry Delete Design

## Intent

매출현황 및 관리에서 날짜를 먼저 선택한 뒤 상품, 매출처, 매입처 기준으로 개별 집계 행을 찾아 수기로 삭제할 수 있게 한다.

## Behavior

- 삭제 화면은 하나로 유지하고 `상품별`, `매출처별`, `매입처별` 모드를 제공한다.
- 조회는 선택한 매출일자 안에서만 수행하며 이름 일부로 검색할 수 있다.
- 상품과 매출처는 손익 매출금액, 매입처는 손익 공급금액을 표시한다.
- 일반 업로드 자료는 선택한 집계 행만 삭제한다.
- 수기 등록 자료는 상품, 매출처, 매입처 중 어느 행에서 삭제해도 같은 수기 등록에 연결된 모든 집계와 업로드 기록을 함께 삭제한다.
- 삭제 전 날짜와 대상명을 표시해 재확인하고, 삭제 후 목록과 대시보드를 즉시 새로 고친다.

## Approaches

- 종류별 API를 각각 추가하는 방식은 단순하지만 조회와 삭제 로직이 세 벌로 중복된다.
- 공통 API에 허용된 종류 값을 전달하는 방식을 선택한다. SQL 테이블명과 이름/금액 열은 서버의 고정 매핑만 사용해 임의 SQL 입력을 막는다.

## Constraints

- 기존 상품별 삭제 API는 호환성을 위해 유지한다.
- 기존 CSS 변경과 `runtime/` 파일은 이번 변경에 포함하지 않는다.
